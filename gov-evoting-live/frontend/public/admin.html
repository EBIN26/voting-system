    Open the election

    Opening fixes the voting window and the number of eligible voters on the blockchain. It cannot be undone. You sign it with the administrator wallet; the server never holds that key.

      Counting

      The votes are encrypted. The result becomes final only when 2 trustees each decrypt the votes and submit the same totals.

      Instructions for the trustees
      1. At least the required number of trustees meet on an offline computer with their key share files.
      2. Run node scripts/tally.js --shares trustee-1.share.json,trustee-2.share.json and type your passphrases.
      3. Each trustee submits the result from their own wallet with node scripts/submit-tally.js.

      Final results

      How anyone can verify these results

      The trustees can publish the election private key. Anyone then runs node scripts/verify-tally.js --key published-election-private-key.pem to re-count the ballots on the blockchain and compare with this result.
